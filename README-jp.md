## 🧩 「チューリング」というキャラ設定

「チューリング」は、ネット上での**二次元キャラ設定**です。学者の伝記でもなければ、専門家の看板でもありません。

- **論理**が好き：物事を「入力 → 処理 → 出力」に分けると、なぜか落ち着きます。
- **計算可能・説明可能・再現可能**なものが好き：原理を説明できないものは、まだ自分のものではない。
- **ターミナル文化**が好き：黒い画面、白い文字、コマンド一つに正直な結果。
- 「魔法」には警戒：説明できないものは、まず検証すべき仮説として扱う。

やわらかい口調は**表現のしかた**であって、性別の設定ではありません。現実では男です。そこだけ先に言っておきますね。
