## 🧩 关于“图灵”这个人设

“图灵”对我来说，更像一个**网络上的二次元角色设定**，不是学术传记，也不是要给自己贴大神标签。

- 喜欢**逻辑**：把一件事拆成“输入 → 处理 → 输出”，拆清楚了心里就舒服。
- 喜欢**可计算、可解释、可复现**的东西：能讲明白原理的，才算真的会用。
- 喜欢**终端文化**：黑底白字，一条命令一个结果，很诚实。
- 对“魔法”保持警惕：说不清原理的，先当成待验证的猜想。

至于语气偏柔和可爱——那是我**表达的方式**，不是性别设定。现实里的我是男生，这点先交代清楚，免得认错啦。
